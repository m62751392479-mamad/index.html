PROJECT TITLE: AGE OF KINGDOMS Create a massive, fully playable, realistic 3D medieval open-world sandbox RPG inspired by Mount & Blade II: Bannerlord. IMPORTANT: The development instructions and programming code may be in English, BUT THE ACTUAL IN-GAME LANGUAGE MUST BE PERSIAN (FARSI). ================================================== 1. IN-GAME LANGUAGE SYSTEM ================================================== The actual playable game must support Persian as a complete interface language. Add a language selection option inside the game's settings. Available language: - Persian (Farsi) When Persian is selected, translate every visible element into natural Persian. This includes: - Main menu - Settings - Character creation - Character names - Kingdom names - City and village names - World map - Quests - Dialogues - NPC conversations - Army management - Soldier recruitment - Battle commands - Weapons and armor - Inventory - Trading - Economy - Diplomacy - Kingdom management - Notifications - Tutorials - Loading screens - Victory and defeat messages Use proper Persian fonts. Support right-to-left text. Make sure Persian letters connect correctly. Do not display untranslated English interface text. Save the selected language between game sessions. ================================================== 2. GAME WORLD ================================================== Create a huge medieval continent with: - Multiple kingdoms - Large cities - Small villages - Castles - Fortresses - Forests - Mountains - Rivers - Lakes - Bridges - Roads - Farms - Military camps - Trading routes The world must be explorable without forced level-based progression. Use procedural generation and optimized world streaming when necessary. ================================================== 3. THIRD-PERSON CHARACTER ================================================== The game must use a third-person camera. Features: - Fully visible player character - Smooth camera movement - Camera rotation - Camera zoom - Walking - Running - Realistic animations - Collision with the environment Mobile controls: - Tap the ground to move toward that location. - Add an optional virtual joystick. - Use touch controls for camera rotation. PC controls: - WASD movement - Mouse camera control - Keyboard interaction ================================================== 4. CHARACTER CREATION ================================================== Allow players to: - Choose a character name - Customize face and appearance - Choose hairstyle and beard - Select clothing - Select starting equipment - Choose starting skills - Select a starting location ================================================== 5. KINGDOMS ================================================== Create several independent medieval kingdoms. Each kingdom must have: - A ruler - Noble families - Lords - Armies - Cities - Villages - Castles - Territories - Flags - Diplomacy - Relationships with other kingdoms Kingdoms must interact independently. They can: - Declare war - Make peace - Form alliances - Conquer settlements - Lose territories - Recruit armies ================================================== 6. CITIES ================================================== Create detailed medieval cities containing: - Defensive walls - Towers - Gates - Streets - Houses - Markets - Shops - Blacksmiths - Taverns - Inns - Barracks - Guards - Merchants - Citizens - City leaders Allow the player to enter cities and interact with NPCs. ================================================== 7. VILLAGES ================================================== Create villages containing: - Houses - Farms - Animals - Farmers - Local leaders - Markets - Resources - Recruitable villagers Villages should have their own economic conditions. ================================================== 8. CASTLES ================================================== Create fully explorable castles with: - Walls - Towers - Gates - Courtyards - Barracks - Storage buildings - Guards - Lords - Defensive positions Allow players to own, manage and defend castles. ================================================== 9. ARMY RECRUITMENT ================================================== Allow players to recruit soldiers from villages and cities. Create different troop types: - Infantry - Archers - Crossbowmen - Cavalry - Heavy cavalry - Spearmen - Elite troops - Guards Each troop type must have different statistics, equipment and appearance. ================================================== 10. SOLDIER PROGRESSION ================================================== Soldiers gain experience over time. Allow them to upgrade into stronger troop classes. Include: - Experience - Training - Equipment upgrades - Different armor - Different weapons - Morale - Daily wages ================================================== 11. ARMY MANAGEMENT ================================================== Create a detailed army management system. Allow players to: - View their soldiers - Recruit troops - Dismiss troops - Upgrade troops - Manage food - Pay wages - Manage morale - Organize formations - Manage companions ================================================== 12. BATTLE COMMANDS ================================================== Allow players to command their armies during battles. Include commands: - Follow me - Hold position - Charge - Retreat - Advance - Form a line - Form a shield wall - Form a circle - Archers hold position - Cavalry charge - Infantry attack Soldiers must respond to commands. ================================================== 13. REAL-TIME BATTLES ================================================== Create real-time medieval battles. Include: - Friendly armies - Enemy armies - Infantry formations - Archers - Cavalry - Commanders - Battle objectives - Victory conditions - Defeat conditions - Experience rewards - Prisoners - Loot The player must actively participate in battles. ================================================== 14. COMBAT SYSTEM ================================================== Create a third-person medieval combat system. Include: - Swords - Spears - Axes - Maces - Bows - Crossbows - Shields - Helmets - Armor Add: - Attacking - Blocking - Dodging - Shield defense - Different attack animations - Health - Stamina - Mounted combat Keep combat non-graphic. ================================================== 15. HORSES ================================================== Allow players to: - Buy horses - Ride horses - Equip horses - Upgrade mounts - Recruit cavalry - Travel faster on horseback ================================================== 16. SIEGE WARFARE ================================================== Create large-scale castle sieges. Include: - Siege towers - Battering rams - Ladders - Catapults - Defensive walls - Castle gates - Defending soldiers - Attacking armies Allow players to attack and defend castles. ================================================== 17. ECONOMY ================================================== Create a dynamic economy. Include: - Gold - Food - Grain - Meat - Wood - Iron - Tools - Horses - Weapons - Armor - Clothing - Trade goods Prices must change depending on supply and demand. ================================================== 18. TRADING ================================================== Allow players to: - Buy goods - Sell goods - Visit markets - Transport goods - Hire caravans - Establish businesses - Manage trade routes - Earn profits ================================================== 19. CHARACTER SKILLS ================================================== Create a progression system with: - Strength - Intelligence - Leadership - Trade - Medicine - Tactics - Engineering - Riding - Weapon skills Allow players to earn experience and improve their skills. ================================================== 20. INVENTORY ================================================== Create a complete inventory system. Include: - Weapons - Armor - Helmets - Shields - Boots - Clothing - Horses - Food - Resources - Trade goods Equipment changes must visibly affect the character model. ================================================== 21. NPC INTERACTIONS ================================================== Create interactive NPCs with different personalities. Allow players to: - Talk to citizens - Talk to merchants - Talk to soldiers - Talk to nobles - Talk to kings - Accept quests - Negotiate - Recruit companions - Make agreements All NPC dialogue must be displayed in Persian when Persian is selected. ================================================== 22. QUEST SYSTEM ================================================== Create different quests: - Escort missions - Delivery missions - Bandit hunting - Village protection - Rescue missions - Military contracts - Trading missions - Kingdom missions - Siege missions Each quest must have Persian descriptions and objectives. ================================================== 23. BANDITS AND ENEMIES ================================================== Create: - Bandit groups - Hostile patrols - Rival clans - Enemy armies - Enemy kingdoms Enemy groups must travel around the world and interact with settlements. ================================================== 24. POLITICS AND DIPLOMACY ================================================== Allow players to: - Negotiate peace - Declare war - Form alliances - Gain influence - Vote on kingdom decisions - Become a noble - Become a ruler ================================================== 25. KINGDOM MANAGEMENT ================================================== Allow players who become rulers to: - Manage territories - Appoint governors - Manage taxes - Recruit armies - Build improvements - Manage diplomacy - Declare wars - Make peace - Manage food supplies - Defend settlements ================================================== 26. SETTLEMENT DEVELOPMENT ================================================== Allow players to improve settlements by constructing: - Farms - Workshops - Barracks - Markets - Walls - Towers - Roads - Storage buildings ================================================== 27. DAY AND NIGHT ================================================== Create a realistic day-night cycle. Include: - Sunrise - Sunset - Night lighting - Torches - Campfires - Night patrols ================================================== 28. WEATHER ================================================== Include: - Sunny weather - Rain - Fog - Snow - Wind - Changing atmospheric conditions ================================================== 29. GRAPHICS ================================================== Use the highest visual quality supported by the platform. Include: - Detailed 3D characters - Realistic medieval architecture - Detailed terrain - High-quality forests - Realistic water - Dynamic lighting - Shadows - Detailed armor - Realistic animations - Atmospheric fog - High-quality textures Avoid primitive placeholder graphics in the final version. ================================================== 30. MOBILE INTERFACE ================================================== Create a professional mobile interface. Include: - Touch movement - Tap-to-move - Camera rotation - Interaction buttons - Inventory button - Map button - Army button - Quest button - Character button - Settings button All interface elements must be in Persian. ================================================== 31. WORLD MAP ================================================== Create a large strategic world map. Show: - Kingdom borders - Cities - Villages - Castles - Armies - Roads - Mountains - Rivers - Trade routes Allow players to select destinations by touching the map. ================================================== 32. SAVE SYSTEM ================================================== Create an automatic save system. Allow players to: - Save their progress - Load previous saves - Continue their adventure - Keep their character - Keep their army - Keep their settlements - Keep their kingdom ================================================== 33. PERFORMANCE ================================================== Optimize the game for mobile devices. Use: - Level of detail - Efficient rendering - Object pooling - World streaming - Optimized textures - Adjustable graphics settings - Efficient NPC simulation The game must run smoothly on supported mobile hardware. ================================================== 34. GAMEPLAY FREEDOM ================================================== Do not force the player into a single story. Allow different playstyles: - Independent adventurer - Merchant - Mercenary - Soldier - Noble - Army commander - Kingdom ruler - Emperor The player must be able to create their own story. ================================================== 35. DEVELOPMENT PRIORITIES ================================================== Build a functional game, not just a visual demonstration. Prioritize working gameplay systems. Do not create buttons that do nothing. Do not create fake menus. All important systems must interact with each other. If the entire game is too large to build at once, create it in development stages. First build a fully playable core prototype containing: 1. Third-person character movement. 2. A large explorable environment. 3. One city. 4. One village. 5. NPC interaction. 6. Soldier recruitment. 7. Army management. 8. Real-time battles. 9. Persian in-game language. 10. Saving and loading. Then expand the world and add the remaining systems. FINAL REQUIREMENT: The result must be a Persian-language medieval sandbox RPG with a living world, kingdoms, armies, cities, villages, castles, trading, diplomacy, battles and complete player freedom. The programming code may be English, but the language experienced by the player must be Persian.
